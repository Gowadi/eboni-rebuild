# Eboni's Rebuild — GitHub Pages

Static campaign landing page for Eboni and Boone after the August 11, 2026 storm in Olde Towne East, Columbus.

## Files

- `index.html` — complete website
- `assets/eboni-boone.jpg` — temporary crop from the campaign preview; replace with a higher-resolution photo when available
- `assets/campaign-preview.png` — campaign screenshot
- `assets/zelle-qr.jpg` — Zelle QR image supplied for the campaign

## Publish with GitHub Pages

1. Create a public GitHub repository named `eboni-rebuild`.
2. Upload `index.html` and the entire `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/eboni-rebuild/`.

## Before launch

- Replace `assets/eboni-boone.jpg` with a high-resolution original photo if available.
- Confirm the Amazon list URL and current needs.
- Confirm Cash App and Venmo handles before publishing.
- Confirm the Zelle QR is current.
- Test every button on mobile.
- Keep the GoFundMe as the primary financial CTA.
